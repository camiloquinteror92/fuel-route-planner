{% load static %} {% comment %} The planner page (fuelroute/web.py::planner_page), served at /api/route/map. A guided tour in six steps, one card at a time: Trip, Route, Fuel stops, Cost, Truck and Assignment (partials/_step_*.html). The map stays on the right from 960px (on top on a phone). The step is kept in the address hash (#trip, #route, #stops, #cost, #truck, #assignment) and the trip in the query string. The server renders only this shell: the form pre-filled from the query string (escaped by the template engine), and the page configuration with /api/about embedded by json_script. It plans nothing and calls no external service. static/fuelroute/js/main.js calls the same GET /api/route that Postman uses and fills the page from the answer. Rule: the visible text has no digits. Every value is a filled by JavaScript from the API answer (route), /api/about (about), browser timings (client) or pure functions of them (derived), or shows a dash when missing. The step numbers come from a CSS counter. Fixed literals are marked data-literal. fuelroute/tests/test_web.py enforces it. {% endcomment %} Fuel Route Planner Skip to content
