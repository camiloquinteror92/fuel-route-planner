First four one-click tries (each starts from the standard truck), then "What changed" against the standard truck, and why, then the settings to set by hand. Defaults ("Default: ...") and limits come from /api/about at run time, so the visible text has no digits, and the server validates every value again. The other settings of the API (corridor_miles, price_policy) have no control: a link that brings them keeps them, and the page names them. The start-tank radios belong to the trip form (form="trip-form"); their label and help are the API's own (/api/about api.start_tank_modes). {% endcomment %}
