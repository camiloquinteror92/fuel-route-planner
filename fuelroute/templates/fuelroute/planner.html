{% load static %} {% comment %} The planner page (fuelroute/web.py::planner_page), served at /api/route/map. A guided tour in six steps, one card at a time: Trip, Route, Fuel stops, Cost, Truck and For Spotter (partials/_step_*.html; the last one's id is "assignment"). The map stays on the right from 960px (on top on a phone). The step is kept in the address hash (#trip, #route, #stops, #cost, #truck, #assignment) and the trip in the query string. The server renders only this shell: the form pre-filled from the query string (escaped by the template engine), and the page configuration with /api/about embedded by json_script. It plans nothing and calls no external service. static/fuelroute/js/main.js calls the same GET /api/route that Postman uses and fills the page from the answer. Rule: the visible text has no digits. Every value is a filled by JavaScript from the API answer (route), the standard truck's answer for the same trip (standard), /api/about (about), browser timings (client) or pure functions of them (derived), or shows a dash when missing. The step numbers come from a CSS counter. Fixed literals are marked data-literal. fuelroute/tests/test_web.py enforces it. Every number explains itself: static/fuelroute/js/explain-ui.js puts a small "i" button after each value (data-no-explain skips one) and inside each span with data-explain="key"; it opens a card with what the value is, where it comes from, how it is calculated (with this trip's numbers), why, and where in the code. The words are in static/fuelroute/js/explain.js (EXPLAINERS); fuelroute/tests/test_explain.py checks every value has one. The header switch "Explain every number" makes the buttons stand out. {% endcomment %} Fuel Route Planner Skip to content
